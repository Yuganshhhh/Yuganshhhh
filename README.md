### 🚀 Featured Projects

#### 🎬 [Movie Match](https://github.com/Yuganshhhh/movies-match-01): Semantic Movie Search & Recommendations
**Java 21 · Spring Boot · Spring AI · Gemini Embeddings**

- Describe a movie in plain English and get the closest matches by **meaning**, not keywords.
- Embeds the movie dataset on startup with `gemini-embedding-001` and ranks results with **cosine similarity implemented from scratch**.
- Two REST endpoints: semantic search and "movies similar to X".

#### 🤖 [AI Agent Tools & Workflow Demo](https://github.com/Yuganshhhh/ai-agent-01)
**Spring Boot · Spring AI · Tool Calling · Gemini API · Java 21**

- Built an autonomous **website generation agent** that creates complete multi-file sites (HTML/CSS/JS) via a plan → write → verify → fix loop.
- Implemented sandboxed file-system tools with path boundary checks to prevent traversal.
- Streaming chat API (SSE) with multi-tool workflows: calculator, live weather & currency exchange.
- Provider-agnostic LLM setup (Gemini via OpenAI-compatible endpoint).

#### 🏋️ [FitPilot](https://github.com/Yuganshhhh/FitPilot): AI-Powered Fitness Platform
**Spring Boot · Spring Cloud · Kafka · Keycloak · MongoDB · Gemini API**

- Built a multi-service fitness platform that generates personalized workout analysis, improvement areas & safety guidelines using **Google Gemini**.
- Decoupled high-frequency activity ingestion from AI analysis with **Apache Kafka** event streaming.
- Centralized auth with **Keycloak (OAuth2/JWT)** at Spring Cloud Gateway + automatic user provisioning.
- Polyglot persistence: PostgreSQL for identities, MongoDB for activities & recommendations.

#### 🔗 [AetherLink](https://github.com/Yuganshhhh): URL Shortener & Analytics
**Spring Boot · PostgreSQL (Neon) · Docker · JWT · Custom Security Filters**

- High-throughput 8-character slug generation with HTTP 302 redirects and click-event tracking.
- Stateless JWT auth using custom Spring Security filters + BCrypt + RBAC.
- Containerized with Docker and deployed on Render with serverless PostgreSQL.
