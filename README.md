### 🚀 Featured Projects

#### 🎬 [Movie Match](https://github.com/Yuganshhhh/movies-match-01)  
**Semantic Movie Search & Recommendations**  
*Java 21 · Spring Boot · Spring AI · Gemini Embeddings*

- Search movies by **meaning**, not keywords — describe a film in plain English and get the closest matches.
- Embeds the full dataset on startup with `gemini-embedding-001` and ranks results using **cosine similarity implemented from scratch**.
- Clean REST API with semantic search + “movies similar to X” endpoints.

#### 🤖 [AI Agent Tools & Workflow Demo](https://github.com/Yuganshhhh/ai-agent-01)  
**Autonomous Website Generation Agent**  
*Spring Boot · Spring AI · Tool Calling · Gemini · Java 21*

- Built an agent that generates complete multi-file websites (HTML/CSS/JS) through a plan → write → verify → fix loop.
- Sandboxed file-system tools with strict path boundary checks.
- Streaming chat API (SSE) with multi-tool support: calculator, live weather, and currency exchange.
- Provider-agnostic LLM setup (Gemini via OpenAI-compatible endpoint).

#### 🏋️ [FitPilot](https://github.com/Yuganshhhh/FitPilot)  
**AI-Powered Fitness Platform**  
*Spring Boot · Spring Cloud · Kafka · Keycloak · MongoDB · Gemini*

- Multi-service platform that generates personalized workout analysis, improvement areas, and safety guidelines using **Google Gemini**.
- Decoupled high-frequency activity ingestion from AI analysis with **Apache Kafka**.
- Centralized auth via **Keycloak (OAuth2/JWT)** at Spring Cloud Gateway with automatic user provisioning.
- Polyglot persistence: PostgreSQL for identities, MongoDB for activities & recommendations.

#### 🔗 [AetherLink](https://github.com/Yuganshhhh)  
**URL Shortener & Analytics**  
*Spring Boot · PostgreSQL (Neon) · Docker · JWT · Custom Security Filters*

- High-throughput 8-character slug generation with HTTP 302 redirects and click-event tracking.
- Stateless JWT authentication using custom Spring Security filters + BCrypt + RBAC.
- Fully containerized and deployed on Render with serverless PostgreSQL.
